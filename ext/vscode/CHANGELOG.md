# Changelog

## 1.0.1

- Renamed to Ferry P2P
- Added a universal package that carries every platform's daemon

## 1.0.0

First Marketplace release.

- Pair machines and send files, secrets, and messages directly over the local network
- Received files are written by the daemon itself, so there is no size limit and a failed save
  never loses the file
- Teammates' online status follows whether they can actually be reached
- Notifications when something arrives, and daemon status in the status bar
